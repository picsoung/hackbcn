This app is a proof-of-concept service for TitanOS TVs which allows groups of people who may differ in taste to find a show which suits all of them. It uses Nebius AI's platform to learn about every person's preferences and suggest movies and shows. It uses SLNG to turn the voice recordings into text, so people don't need to painstakingly type each letter into their TV. It uses Mastra to run two workflows: processing preferences and producing the final recommendations.
