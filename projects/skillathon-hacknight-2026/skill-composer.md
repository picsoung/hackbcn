A meta-skill that audits your entire skill library. It scans all skills, maps relationships, detects
overlaps and gaps, scores each skill on composability (1–5), and proposes targeted rewrites. Run it when your
skill collection has grown and you want to keep it clean and well-structured.

## Installation

```sh
npx skills add panrosk/skill-composer
```
