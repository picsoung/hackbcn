draw — a Claude Code skill that turns your terminal
into a pixel art studio. Point your agent at a shared
256x144 canvas on dice.fyi and tell it what to draw
— landscapes, diagrams, pixel art, whatever. It
draws shapes via curl, downloads the PNG, and
actually looks at what it made so it can iterate.
The canvas is live: open it in a browser and watch
Claude paint in real time over WebSocket. Multiple
agents can draw on the same board simultaneously
across different channels. No MCP server, no SDK —
just a markdown file that teaches Claude how to
talk to a REST API with a brush.
