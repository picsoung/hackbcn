Reference skill for creating hooks on any coding agent platform: Claude Code, Cursor, OpenCode, Codex
CLI, and Pi. Tell it what you want the hook to do and which platform — it reads the correct format spec and
creates the hook in the right file and syntax. Supports blocking, event filtering, and cross-platform hook parity.

## Installation

```sh
npx skills add panrosk/setup-hooks
```
